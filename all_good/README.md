# all_good

Инструмент для нарезки повторяющейся фразы из сериала в один видеофайл.

Работает в два прохода, по аналогии с [`transcribe/`](../transcribe/README.md) (та же модель GigaAM-v3):

1. **Проход 1** — `scan_transcribe.py` один раз просматривает все серии, распознаёт речь
   и для каждого видеофайла сохраняет рядом текстовый файл с сегментами речи и их таймстампами.
2. **Проход 2** — `cut_phrases.py` ищет заданные фразы в файлах из прохода 1, вырезает из исходных
   видео все совпадающие куски и для каждой фразы складывает их в отдельную папку: клипы по
   отдельности + один склеенный файл со всеми повторами подряд.

## Проход 1 — `scan_transcribe.py`

**Особенности:**
- Границы сегментов — по реальным паузам речи (VAD, `pyannote/segmentation-3.0`), а не по
  фиксированной нарезке по времени. Это даёт заметно более точные таймстампы начала/конца
  фразы, чем при пропорциональной оценке по длине текста внутри чанка.
- Таймстампы — с точностью до миллисекунд (`HH:MM:SS.mmm`).
- Потоковая запись: строка результата пишется в файл сразу после распознавания каждого сегмента
  (не после всей серии) — можно смотреть прогресс вживую, открыв `<серия>....segments.txt.partial`.
- Конвейер: пока GPU распознаёт текущую серию, в фоновом потоке уже режется звук следующей
  (ffmpeg — это диск/сеть/CPU, с GPU не конкурирует).
- Идемпотентно и безопасно для повторного запуска: файл-результат появляется под финальным именем
  только когда серия обработана целиком (`.partial` → переименование). Если рядом с видео уже есть
  готовый файл непустого размера — серия пропускается (можно прервать и продолжить позже,
  `--force` — пересчитать). Пустой результат (0 байт) тоже переобрабатывается автоматически.
- Результат сохраняется рядом с исходным видео (сеть/сетевой диск — не в репозитории).

**Использование:**
```powershell
# Показывает HELP (без аргументов — справка, без ошибки)
python scan_transcribe.py

# Просмотреть все серии из обеих папок сериала на сетевом диске
python scan_transcribe.py "\\luigi\S-Downloads\From.S03.WEB-DLRip.LF" "\\luigi\S-Downloads\From.S04.WEB-DLRip.LF"

# С явным устройством и более короткими сегментами (точнее таймстампы, медленнее)
python scan_transcribe.py "\\luigi\S-Downloads\From.S03.WEB-DLRip.LF" --device cuda --max-segment-sec 8

# Пересчитать уже готовые файлы
python scan_transcribe.py "\\luigi\S-Downloads\From.S03.WEB-DLRip.LF" --force
```

**Выход:** рядом с каждым `<серия>.avi` создаётся `<серия>.gigaam-<revision>.segments.txt`:
```
[00:00:12.340 - 00:00:18.900] Текст первого сегмента речи.
[00:00:19.100 - 00:00:26.450] Текст следующего сегмента речи.
```

## Проход 2 — `cut_phrases.py`

**Особенности:**
- Поиск — подстрокой, без учёта регистра и пунктуации (нормализация как в анализе частот).
- `--edge-only` — резать только совпадения, где фраза стоит в начале или в конце сегмента речи,
  пропускать середину. Если фраза найдена в середине длинного сегмента ("Всё в порядке. **Всё
  хорошо.** Эй, да, я больше не хочу хоронить детей."), вырезался бы весь сегмент целиком —
  с посторонним текстом до и после. У начала/конца сегмента таймстамп ближе к самой фразе.
- `--isolate-silence` — для совпадений на краю сегмента (см. `--edge-only`) ищет реальную паузу
  с внутренней стороны фразы (там, где сегмент продолжается другим текстом) и режет по ней вместо
  всего сегмента. Ищет **только внутри уже известных границ сегмента** — наружу не выходит
  никогда, поэтому не может зацепить что-то за его пределами (более ранняя версия смотрела и за
  границы сегмента тоже и из-за этого иногда обрезала соседние реплики пополам — отказались от
  этого подхода). Если фраза в середине сегмента или паузы с нужной стороны физически нет
  (быстрый диалог реплика-в-реплику без пауз) — просто не сужает, работает как без флага.
- `--best-of-sec N` — не вся нарезка, а только лучшие совпадения на ~N секунд суммарно (не строго —
  последний клип может слегка превысить порог). "Лучшесть": сначала совпадения, реально
  изолированные тишиной, затем — чем короче итоговый клип, тем выше (короче = меньше шанс, что
  внутрь попало что-то постороннее). Включает `--isolate-silence` автоматически. Анализ пауз для
  всех совпадений (сеть/ffmpeg, не CPU) считается в 6 потоков параллельно, с логом прогресса.
- Подрезка ведущей тишины (всегда включена, без флага): у ~24% сегментов VAD-граница
  начинается на 0.3-2 сек раньше реальной речи (склейка с соседним тихим/невнятным спаном, для
  которого ASR не выдал текста — проверено вручную через `ffmpeg silencedetect`). Перед вырезкой
  каждого клипа скрипт проверяет первые секунды на тишину и сдвигает начало окна к реальной речи.
- Несколько фраз-аргументов трактуются как **ИЛИ**: один общий результат на все совпадения сразу
  (сегмент, подошедший под несколько фраз, режется один раз). Удобно для синонимов ("надо уходить
  отсюда" / "надо убираться отсюда") — не нужно потом вручную сводить два отдельных ролика в один.
  Папка/файл называются по всем фразам через " или ": `cuts/<фраза1>_или_<фраза2>/clips/*.mp4`
  (отдельные короткие клипы, имя = серия + таймкод) и `cuts/<фраза1>_или_<фраза2>/<...>.mp4`
  (все клипы склеены подряд). Если нужны отдельные ролики на разные фразы — запусти скрипт
  по разу на каждую.
- `--padding-ms` — запас по времени до/после сегмента при вырезании, в миллисекундах (по умолчанию 300).
- Клипы перекодируются (`libx264`/`aac`, единый fps `24000/1001` и частота дискретизации звука
  48кГц на каждом клипе), а склейка тоже перекодирует, а не `-c copy`. Без этого встречается
  подвисание видео при непрерывном звуке в проигрывателе на стыках клипов: у части серий (замечено
  на 4 сезоне) fps в контейнере записан как `2997/125` вместо `24000/1001` у остальных — то же
  значение (23.976), но другое рациональное представление, которое ломает склейку "в лоб".

**Использование:**
```powershell
# Показывает HELP (без аргументов — справка, без ошибки)
python cut_phrases.py

# Найти и нарезать одну фразу
python cut_phrases.py "всё хорошо" --folders "\\luigi\S-Downloads\From"

# Несколько фраз-синонимов — трактуются как ИЛИ, один общий результат
python cut_phrases.py "надо уходить отсюда" "надо убираться отсюда" --folders "\\luigi\S-Downloads\From"

# Только начало/конец сегмента — чище нарезка, без лишнего текста вокруг
python cut_phrases.py "всё хорошо" --folders "\\luigi\S-Downloads\From" --edge-only

# Резать по реальной паузе внутри сегмента — клип уже не тянется на весь сегмент
python cut_phrases.py "что происходит" --folders "\\luigi\S-Downloads\From" --edge-only --isolate-silence

# Минута лучших повторов фразы (сначала изолированные тишиной, потом короче — лучше)
python cut_phrases.py "что происходит" --folders "\\luigi\S-Downloads\From" --edge-only --best-of-sec 60

# Другая папка вывода и больший запас по краям
python cut_phrases.py "всё хорошо" --folders "\\luigi\S-Downloads\From" --output-dir "D:\cuts" --padding-ms 500
```

**Выход:**
```
cuts/
  всё_хорошо/
    всё_хорошо.mp4                          # склейка всех повторов подряд
    clips/
      From.S01E01....RGzsRutracker_00-02-55-025.mp4
      From.S01E01....RGzsRutracker_00-41-09-991.mp4
      ...
```

## Конфигурация

`.env` (копия — `.env.example`):

| Переменная | Назначение |
|---|---|
| `HF_TOKEN` | Токен Hugging Face для `pyannote/segmentation-3.0` (VAD внутри GigaAM `transcribe_longform`) |
| `FFMPEG_BIN` | Путь к DLL FFmpeg (Windows) |
| `scan_transcribe.config.revision` | Ревизия GigaAM-v3 (`e2e_rnnt` по умолчанию, `e2e_ctc`) |
| `scan_transcribe.config.device` | `auto` / `cpu` / `cuda` |
| `scan_transcribe.config.max-segment-sec` | Макс. длительность сегмента VAD — меньше значение → точнее таймстампы, но больше проходов ASR |
| `scan_transcribe.config.min-segment-sec` | Мин. длительность сегмента VAD |
| `cut_phrases.config.output-dir` | Папка для нарезки (по умолчанию `all_good/cuts`) |
| `cut_phrases.config.padding-ms` | Запас по времени до/после сегмента при вырезании клипа (мс) |
| `cut_phrases.config.silence-noise-db` | Порог тишины для подрезки ведущей тишины (dB, по умолчанию -30) |
| `cut_phrases.config.silence-min-sec` | Мин. длительность тишины, чтобы её подрезать (сек, по умолчанию 0.3) |
| `cut_phrases.config.silence-probe-sec` | Сколько секунд от начала окна проверять на тишину (по умолчанию 2.0) |

CLI-флаг всегда переопределяет значение из `.env`.

**Важно:** на Hugging Face нужно принять условия доступа к модели
[`pyannote/segmentation-3.0`](https://huggingface.co/pyannote/segmentation-3.0) под аккаунтом,
чьим токеном указан `HF_TOKEN`.

## Установка

```powershell
cd all_good
pip install -r requirements.txt
```

## Структура

| Файл | Назначение |
|---|---|
| `scan_transcribe.py` | Проход 1: распознавание речи всех видео с таймстампами по VAD-сегментам |
| `cut_phrases.py` | Проход 2: поиск фраз в результатах прохода 1 и нарезка видео |
| `all_good_config.py` | Константы, пути, значения из `.env` |
| `all_good_dto.py` | Pydantic-модели (`SegmentTranscript`, `PhraseMatch`, `ScanReport`, `ProcessingStatus`) |
| `all_good_utils.py` | ffmpeg, поиск файлов, парсинг сегментов, статус обработки, логирование |
